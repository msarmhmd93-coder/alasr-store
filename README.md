# مشغل العسر

موقع متجر صغير لعرض منتجات المعمل مثل العبايات والبراقع والدفايات والنقابات.

## التشغيل

1. افتح مجلد المشروع.
2. شغل السيرفر محليًا:

```bash
py -m http.server 8000
```

3. افتح هذا الرابط في المتصفح:

```text
http://localhost:8000
```

## ملاحظات

- المنتجات تُحفظ داخل المتصفح باستخدام localStorage.
- يمكنك إضافة منتج جديد من قسم "إضافة منتج".
- يمكنك تحميل صورة جديدة للمنتج من جهازك.
